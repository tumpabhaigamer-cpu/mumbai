How this is used in outreach

01

Find the business

Search or filter the directory. Each card names the design system the concept was built in, so a client sees two or three distinct directions rather than one template.

02

Open the concept

The demo lives at a query string: index.html?b=business-slug. Each of the 100 links opens independently, so a single preview can be sent without exposing the rest.

03

Copy link, then talk

Use Copy link or the WhatsApp button inside the preview. WhatsApp opens a blank chat picker with a prefilled message — no recipient number is embedded or guessed.

About this deck

Mumbai Studio Showcase is an independent outreach concept. It pairs 100 Mumbai small businesses with six category-specific design systems — Aperture (interior design), Veil (bridal makeup), Loom (couture & jewellery), Crumb (custom cakes), Frame (weddings & films) and Ledger (dental, fitness, auto & real estate).

What this is not

Not any business’s official website. Not a portfolio, testimonial, price list or credential claim. All descriptive copy is illustrative and marked for confirmation before any use.

Assets

Ten AI-generated editorial images and one generated ambient loop are used illustratively. Typefaces are self-hosted. No trackers, no cookies, no third-party requests.

Names are used solely to identify the prospect for whom a mock-up was prepared. If you are named here and would prefer not to be, this deck can be removed on request. Concept demo — brand details and copy for illustration; confirm before use.
